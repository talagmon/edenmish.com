A separately approved user-controlled loader must inject authority and transport, with the exact approved plan hash. Live flags-OFF and browser callback verification remain incomplete activation gates. Never infer live readiness from these mock tests.

```sh
node --test shutdown-adapters.test.mjs shutdown-policy.test.mjs
node shutdown-dry-run.mjs
```

The generated dry-run receipt is local output and is not versioned. Synthetic order, recipient and account IDs in fixtures are test-only. No payment, provider call, callback, deployment or financial deletion is authorized by these tools.
